🎲 Dice Game (React.js)
A simple Dice Game built with React.js, featuring an interactive UI and random dice rolls.

🚀 Features
✔️ Roll the dice with a button click
✔️ Randomized dice outcomes
✔️ Responsive and dynamic UI
✔️ State management with React hooks
✔️ Smooth animations (if implemented)
